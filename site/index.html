CONTEXT & HISTORY

Two useful starting points.

Context starts from history plus offseason roster and recruiting information. History starts from prior program performance only. Both use the same in-season game-updating engine.

METHODOLOGY

Games revise the forecast.

Preseason beliefs begin with historical program performance; Context adds offseason information. Completed FBS/FCS games update those beliefs, with score margin and opponent strength affecting the posterior. Lower-division games are excluded.
