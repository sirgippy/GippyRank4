About these rankings

Predictive

Combines preseason information with eligible game results to estimate current rank distributions. Context includes roster and recruiting information; History starts from prior program performance.

Performance

Uses eligible games to estimate the quality implied by a team's schedule and results, with Predictive Context estimates for opponent quality.

Performance is not standings, strength of record, or postseason deservingness. Teams without an eligible game are shown as NR.
